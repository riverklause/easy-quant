## 指标架构概述

### 指标类层次结构

Easy-Quant的指标系统采用分层架构：

```
BaseIndicator (抽象基类)
├── TechnicalIndicator (技术指标基类，包含原基本面指标)
├── StatisticalIndicator (统计指标基类)
└── BaseFactor (因子基类)
    ├── TechnicalFactor (技术因子)
    ├── FundamentalFactor (基本面因子)
    ├── SentimentFactor (情绪因子)
    └── CompositeFactor (复合因子)
```

### 指标分类优化

最新版本对指标分类进行了优化：

1. **技术指标**：包含原技术指标和基本面指标，统一使用`TechnicalIndicator`作为基类
2. **因子指标**：保持独立，使用`BaseFactor`及其子类

这种分类方式简化了指标系统结构，同时保持了功能的完整性。

### 核心抽象方法

所有指标都必须实现以下抽象方法：

- `calculate()`: 计算指标值
- `validate_data()`: 验证输入数据

## 简单使用

指标模块提供了两种使用方式：简单直接使用和批量管理使用。

### 直接实例化使用（推荐）

最简单的方式是直接导入指标类，实例化后调用 `calculate()` 方法：


### 基础技术指标实现

```python
from indicators.base.base_indicator import TechnicalIndicator
import pandas as pd
import numpy as np

class SimpleMovingAverage(TechnicalIndicator):
    """简单移动平均线指标"""
    
    def __init__(self, period=20, name="SMA", **kwargs):
        super().__init__(
            name=name,
            data_fields=['close'],  # 需要的数据字段
            output_fields=['sma'],  # 输出的指标字段
            **kwargs
        )
        self.period = period
    
    def calculate(self, data, **kwargs):
        """计算简单移动平均线"""
        # 验证数据
        self.validate_data(data)
        
        if isinstance(data, pd.DataFrame):
            # 从DataFrame中提取收盘价
            close_prices = data['close']
        elif isinstance(data, pd.Series):
            # 直接使用Series
            close_prices = data
        else:
            raise TypeError("不支持的数据类型")
        
        # 计算SMA
        sma = close_prices.rolling(window=self.period).mean()
        
        # 返回结果
        if isinstance(data, pd.DataFrame):
            # 返回DataFrame格式
            result = data.copy()
            result[f'sma_{self.period}'] = sma
            return result
        else:
            # 返回Series格式
            return sma
    
    def validate_data(self, data):
        """验证输入数据"""
        if isinstance(data, pd.DataFrame):
            if 'close' not in data.columns:
                raise ValueError("DataFrame必须包含'close'列")
        elif isinstance(data, pd.Series):
            if len(data) < self.period:
                raise ValueError(f"数据长度不足，至少需要{self.period}个数据点")
        else:
            raise TypeError("数据类型必须是DataFrame或Series")

# 使用示例
sma_20 = SimpleMovingAverage(period=20, name="SMA_20")
```

```python
class MACD(TechnicalIndicator):
    """MACD指标（移动平均收敛散度）"""
    
    def __init__(self, fast_period=12, slow_period=26, signal_period=9, name="MACD", **kwargs):
        super().__init__(
            name=name,
            data_fields=['close'],
            output_fields=['macd', 'signal', 'histogram'],
            **kwargs
        )
        self.fast_period = fast_period
        self.slow_period = slow_period
        self.signal_period = signal_period
    
    def calculate(self, data, **kwargs):
        """计算MACD指标"""
        self.validate_data(data)
        
        if isinstance(data, pd.DataFrame):
            close_prices = data['close']
        else:
            close_prices = data
        
        # 计算EMA
        ema_fast = close_prices.ewm(span=self.fast_period).mean()
        ema_slow = close_prices.ewm(span=self.slow_period).mean()
        
        # 计算MACD线
        macd_line = ema_fast - ema_slow
        
        # 计算信号线
        signal_line = macd_line.ewm(span=self.signal_period).mean()
        
        # 计算柱状图
        histogram = macd_line - signal_line
        
        # 返回结果
        result = pd.DataFrame({
            'macd': macd_line,
            'signal': signal_line,
            'histogram': histogram
        })
        
        return result
    
    def validate_data(self, data):
        """验证输入数据"""
        min_period = max(self.fast_period, self.slow_period, self.signal_period)
        
        if isinstance(data, pd.DataFrame):
            if 'close' not in data.columns:
                raise ValueError("DataFrame必须包含'close'列")
            if len(data) < min_period:
                raise ValueError(f"数据长度不足，至少需要{min_period}个数据点")
        elif isinstance(data, pd.Series):
            if len(data) < min_period:
                raise ValueError(f"数据长度不足，至少需要{min_period}个数据点")
        else:
            raise TypeError("数据类型必须是DataFrame或Series")

# 使用示例
macd = MACD(fast_period=12, slow_period=26, signal_period=9)
```

```python
class RSI(TechnicalIndicator):
    """相对强弱指数指标"""
    
    def __init__(self, period=14, name="RSI", **kwargs):
        super().__init__(
            name=name,
            data_fields=['close'],
            output_fields=['rsi'],
            **kwargs
        )
        self.period = period
    
    def calculate(self, data, **kwargs):
        """计算RSI指标"""
        self.validate_data(data)
        
        if isinstance(data, pd.DataFrame):
            close_prices = data['close']
        else:
            close_prices = data
        
        # 计算价格变动
        delta = close_prices.diff()
        
        # 分离上涨和下跌
        gain = (delta.where(delta > 0, 0)).rolling(window=self.period).mean()
        loss = (-delta.where(delta < 0, 0)).rolling(window=self.period).mean()
        
        # 计算RS
        rs = gain / loss
        
        # 计算RSI
        rsi = 100 - (100 / (1 + rs))
        
        # 返回结果
        if isinstance(data, pd.DataFrame):
            result = data.copy()
            result[f'rsi_{self.period}'] = rsi
            return result
        else:
            return rsi
    
    def validate_data(self, data):
        """验证输入数据"""
        if isinstance(data, pd.DataFrame):
            if 'close' not in data.columns:
                raise ValueError("DataFrame必须包含'close'列")
            if len(data) < self.period + 1:  # +1 for diff
                raise ValueError(f"数据长度不足，至少需要{self.period + 1}个数据点")
        elif isinstance(data, pd.Series):
            if len(data) < self.period + 1:
                raise ValueError(f"数据长度不足，至少需要{self.period + 1}个数据点")
        else:
            raise TypeError("数据类型必须是DataFrame或Series")

# 使用示例
rsi_14 = RSI(period=14)
```

```python
from indicators.base.base_indicator import TechnicalIndicator
import pandas as pd

class FinancialRatioIndicator(TechnicalIndicator):
    """财务比率指标基类"""
    
    def __init__(self, name, description, data_fields, output_fields, **kwargs):
        super().__init__(
            name=name,
            data_fields=data_fields,
            output_fields=output_fields,
            **kwargs
        )
        self.description = description
    
    def calculate_ratio(self, numerator, denominator):
        """计算比率，处理分母为零的情况"""
        if denominator == 0 or pd.isna(denominator):
            return None
        return numerator / denominator
    
    def validate_financial_data(self, data):
        """验证财务数据"""
        if isinstance(data, pd.DataFrame):
            missing_fields = [field for field in self.data_fields if field not in data.columns]
            if missing_fields:
                raise ValueError(f"缺少财务数据字段: {missing_fields}")
        elif isinstance(data, dict):
            missing_fields = [field for field in self.data_fields if field not in data]
            if missing_fields:
                raise ValueError(f"缺少财务数据字段: {missing_fields}")
        else:
            raise TypeError("财务数据必须是DataFrame或字典")
```

```python
class ROEIndicator(FinancialRatioIndicator):
    """净资产收益率指标"""
    
    def __init__(self, name="ROE", **kwargs):
        super().__init__(
            name=name,
            description="净资产收益率，衡量公司盈利能力",
            data_fields=['net_income', 'shareholders_equity'],
            output_fields=['roe'],
            **kwargs
        )
    
    def calculate(self, data, **kwargs):
        """计算ROE"""
        self.validate_financial_data(data)
        
        if isinstance(data, pd.DataFrame):
            # 从DataFrame计算
            net_income = data['net_income']
            shareholders_equity = data['shareholders_equity']
            
            roe = net_income / shareholders_equity
            
            result = data.copy()
            result['roe'] = roe
            return result
        
        elif isinstance(data, dict):
            # 从字典计算
            net_income = data.get('net_income')
            shareholders_equity = data.get('shareholders_equity')
            
            roe = self.calculate_ratio(net_income, shareholders_equity)
            
            return {'roe': roe}
    
    def validate_data(self, data):
        """验证数据"""
        self.validate_financial_data(data)

class DebtToEquityRatio(FinancialRatioIndicator):

    def __init__(self, name="Debt_to_Equity", **kwargs):

    def calculate(self, data, **kwargs):

            debt_to_equity = self.calculate_ratio(total_liabilities, shareholders_equity)

    def validate_data(self, data):
```

```python
class AltmanZScore(FundamentalIndicator):
    """Altman Z-Score财务风险预警指标"""
    
    def __init__(self, name="Altman_Z_Score", **kwargs):
        super().__init__(
            name=name,
            description="Altman Z-Score，用于预测企业破产风险",
            data_fields=[
                'working_capital', 'total_assets', 'retained_earnings',
                'ebit', 'market_value_equity', 'total_liabilities', 'sales'
            ],
            output_fields=['z_score', 'risk_level'],
            **kwargs
        )
    
    def calculate(self, data, **kwargs):
        """计算Altman Z-Score"""
        self.validate_data(data)
        
        if isinstance(data, pd.DataFrame):
            # 从DataFrame计算
            working_capital = data['working_capital']
            total_assets = data['total_assets']
            retained_earnings = data['retained_earnings']
            ebit = data['ebit']
            market_value_equity = data['market_value_equity']
            total_liabilities = data['total_liabilities']
            sales = data['sales']
            
            # 计算Z-Score的五个组成部分
            x1 = working_capital / total_assets  # 营运资本/总资产
            x2 = retained_earnings / total_assets  # 留存收益/总资产
            x3 = ebit / total_assets  # 息税前利润/总资产
            x4 = market_value_equity / total_liabilities  # 权益市值/总负债
            x5 = sales / total_assets  # 销售额/总资产
            
            # 计算Z-Score
            z_score = 1.2 * x1 + 1.4 * x2 + 3.3 * x3 + 0.6 * x4 + 1.0 * x5
            
            # 评估风险级别
            risk_level = pd.cut(z_score, 
                               bins=[-float('inf'), 1.8, 3.0, float('inf')],
                               labels=['高风险', '灰色区域', '低风险'])
            
            result = data.copy()
            result['z_score'] = z_score
            result['risk_level'] = risk_level
            return result
        
        elif isinstance(data, dict):
            # 从字典计算（单次计算）
            working_capital = data.get('working_capital', 0)
            total_assets = data.get('total_assets', 1)  # 避免除零
            retained_earnings = data.get('retained_earnings', 0)
            ebit = data.get('ebit', 0)
            market_value_equity = data.get('market_value_equity', 0)
            total_liabilities = data.get('total_liabilities', 1)  # 避免除零
            sales = data.get('sales', 0)
            
            # 计算Z-Score
            x1 = working_capital / total_assets
            x2 = retained_earnings / total_assets
            x3 = ebit / total_assets
            x4 = market_value_equity / total_liabilities
            x5 = sales / total_assets
            
            z_score = 1.2 * x1 + 1.4 * x2 + 3.3 * x3 + 0.6 * x4 + 1.0 * x5
            
            # 评估风险级别
            if z_score < 1.8:
                risk_level = '高风险'
            elif z_score < 3.0:
                risk_level = '灰色区域'
            else:
                risk_level = '低风险'
            
            return {
                'z_score': z_score,
                'risk_level': risk_level
            }
    
    def validate_data(self, data):
        """验证财务数据"""
        self.validate_financial_data(data)
```

```python
import importlib

def load_indicator_from_module(module_path, class_name, **kwargs):
    """从模块动态加载指标"""
    
    try:
        # 导入模块
        module = importlib.import_module(module_path)
        
        # 获取指标类
        indicator_class = getattr(module, class_name)
        
        # 创建指标实例
        indicator = indicator_class(**kwargs)
        
        return indicator
    except (ImportError, AttributeError) as e:
        print(f"加载指标失败: {e}")
        return None
```

## 指标计算器使用

### 双缓存模式说明

指标计算器支持两种缓存模式，适应不同的使用场景：

| 模式 | 缓存策略 | 适用场景 |
|------|----------|----------|
| **history** | hash对比 + TTL淘汰 | 历史数据回测、选股 |
| **realtime** | 覆盖更新 | 实时监控、策略执行 |

### 历史模式（默认）

```python
from indicators.base.calculator import IndicatorCalculator
```

## 性能优化技巧

### 缓存的必要性

指标计算，特别是技术指标（如 SMA、EMA、RSI 等）涉及大量的滚动窗口计算。在以下场景中，缓存能显著提升性能：

1. **实时数据流更新**：当新数据与之前相同时，直接返回缓存结果，避免重复计算
2. **多指标批量计算**：同一数据源计算多个指标时，已计算的指标可复用
3. **回测/模拟分析**：相同数据重复计算不同策略时，大幅提升性能
4. **用户界面刷新**：短时间内多次请求相同数据，直接从缓存返回
5. **多策略组合**：多个策略共用指标计算结果时，共享缓存

`IndicatorCalculator` 内置了缓存机制，默认配置：
- 缓存大小：300 条
- TTL：3600 秒
- 自动 LRU 淘汰

### 向量化计算

```python
import numpy as np

class VectorizedIndicator(TechnicalIndicator):
    """使用向量化计算的指标"""
    
    def calculate(self, data, **kwargs):
        """向量化计算"""
        self.validate_data(data)
        
        if isinstance(data, pd.DataFrame):
            close_prices = data['close'].values  # 转换为numpy数组
        else:
            close_prices = data.values
        
        # 使用numpy进行向量化计算
        # 例如：计算收益率
        returns = np.diff(close_prices) / close_prices[:-1]
        
        # 计算波动率（年化）
        volatility = np.std(returns) * np.sqrt(252) * 100  # 年化百分比
        
        return {
            'returns': returns,
            'volatility': volatility
        }
```
