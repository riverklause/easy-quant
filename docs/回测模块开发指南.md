## 快速开始

### 基本使用示例

```python
from backtest import BacktestEngine, HistoricalDataFeed
from strategy.technical_strategy import TechnicalStrategy
from indicators.technical.momentum import RSI

# 1. 创建策略
class RSIStrategy(TechnicalStrategy):
    def __init__(self):
        super().__init__(name="RSI_Strategy")
        self.add_required_indicator('rsi_14')

    def generate_signals(self, data, **kwargs):
        signals = []
        rsi = data.get('rsi_14')

        if rsi is not None and not rsi.empty:
            current_rsi = rsi.iloc[-1]

            if current_rsi < 30:  # RSI超卖，买入
                signals.append({'type': 'BUY', 'price': data['close'].iloc[-1]})
            elif current_rsi > 70:  # RSI超买，卖出
                signals.append({'type': 'SELL', 'price': data['close'].iloc[-1]})

        return signals

# 2. 创建回测引擎
strategy = RSIStrategy()
engine = BacktestEngine(
    strategy=strategy,
    initial_capital=1000000,  # 初始资金100万
    commission_rate=0.001,    # 佣金0.1%
    slippage=0.001           # 滑点0.1%
)

# 3. 执行回测
result = engine.run(
    start_date='2023-01-01',
    end_date='2024-12-31',
    symbols=['AAPL', 'GOOG', 'MSFT'],
    frequency='daily'
)

# 4. 查看结果
print(f"总收益率: {result.performance_metrics['total_return']:.2%}")
print(f"年化收益率: {result.performance_metrics['annual_return']:.2%}")
print(f"夏普比率: {result.performance_metrics['sharpe_ratio']:.2f}")
print(f"最大回撤: {result.risk_metrics['max_drawdown']:.2%}")
```

## 核心组件

### 1. BacktestEngine（回测引擎）

回测引擎是整个模块的核心，负责协调数据加载、策略执行和结果生成。

```python
from backtest import BacktestEngine

# 初始化参数
engine = BacktestEngine(
    strategy=strategy,                    # 策略实例或策略列表
    datafeed=None,                         # 历史数据源（可选）
    initial_capital=1000000,              # 初始资金
    commission_rate=0.001,                 # 佣金费率
    slippage=0.0,                         # 滑点
    risk_free_rate=0.03                   # 无风险利率
)
```

**主要方法：**

| 方法 | 说明 |
|------|------|
| run() | 同步执行回测 |
| run_async() | 异步执行回测 |
| stop() | 停止回测 |
| get_results() | 获取回测结果 |
| get_portfolio() | 获取组合管理器 |
| get_data() | 获取回测数据 |

### 2. Portfolio（组合管理器）

组合管理器负责模拟真实交易环境的持仓管理、收益计算和现金管理。

```python
from backtest import Portfolio

portfolio = Portfolio(

```

**主要方法：**

| sell() | 卖出股票 |

| reset() | 重置组合 |

## 绩效分析

### PerformanceAnalyzer（绩效分析器）

绩效分析器计算策略的各项收益指标。

```python
from backtest import PerformanceAnalyzer

analyzer = PerformanceAnalyzer(risk_free_rate=0.03)

# 分析收益率序列
performance = analyzer.analyze(
    returns=returns_series,              # 策略收益率序列
    benchmark_returns=benchmark_returns, # 基准收益率序列（可选）
    periods_per_year=252                 # 每年交易日数
)
```

**计算的绩效指标：**

| 指标 | 说明 |
|------|------|
| total_return | 总收益率 |
| annual_return | 年化收益率 |
| cumulative_returns | 累计收益率曲线 |
| volatility | 波动率 |
| sharpe_ratio | 夏普比率 |
| sortino_ratio | 索提诺比率 |
| calmar_ratio | 卡玛比率 |
| alpha | Alpha（超额收益） |
| beta | Beta（市场风险） |
| information_ratio | 信息比率 |

### 使用示例

```python
# 获取收益率序列
returns = portfolio.get_returns_series()

# 创建绩效分析器
analyzer = PerformanceAnalyzer(risk_free_rate=0.03)

# 分析绩效
metrics = analyzer.analyze(returns)

# 打印关键指标
print(f"总收益率: {metrics['total_return']:.2%}")
print(f"年化收益率: {metrics['annual_return']:.2%}")
print(f"夏普比率: {metrics['sharpe_ratio']:.2f}")
print(f"波动率: {metrics['volatility']:.2%}")
```

| kurtosis | 峰度 |

## 结果存储

### BacktestResult（回测结果）

回测结果包含完整的回测数据和分析结果。

```python
from backtest import BacktestResult

# 访问结果
result = engine.get_results()

# 结果属性
result.strategy_name          # 策略名称
result.start_date            # 回测开始日期
result.end_date              # 回测结束日期
result.initial_capital       # 初始资金
result.final_capital         # 最终资金
result.equity_curve          # 权益曲线
result.trades                # 交易记录
result.performance_metrics   # 绩效指标
result.risk_metrics          # 风险指标
result.trade_metrics         # 交易指标
result.benchmark_returns     # 基准收益率
result.config                # 回测配置
```
