# Easy-Quant 策略模块架构文档

## 📋 概述

本文档详细介绍了Easy-Quant策略模块的架构设计，包括重构后的职责划分、核心组件交互和使用方法。

## 🏗️ 架构设计原则

### 1. 单一职责原则

- **StrategyManager**: 策略管理和协调
- **StrategyExecutor**: 策略执行协调和统计
- **IndicatorCalculator**: 指标计算和缓存管理

### 2. 消除功能重叠

- 移除重复的策略注册逻辑
- 移除重复的指标缓存逻辑
- 清晰的接口边界

### 3. 依赖倒置原则

- 高层模块不依赖低层模块
- 抽象不依赖具体实现
- 通过接口进行协作

## 🔄 协作流程

### 1. 普通单策略执行流程

```python
# 1. StrategyManager接收执行请求
signals = manager.generate_signals(strategy_id, raw_data)

# 2. StrategyManager协调执行
#    - 获取策略实例
#    - 使用executor执行策略
#    - 记录信号和触发事件

# 3. StrategyExecutor执行策略
#    - 获取策略所需指标
#    - 使用calculator计算指标
#    - 执行策略生成信号
#    - 更新执行统计

# 4. IndicatorCalculator计算指标
#    - 检查缓存
#    - 计算指标（如未缓存）
#    - 更新缓存
#    - 返回指标数据
```

### 2. 分离式执行流程（批量策略）

对于多个策略，可以先批量预计算指标，再批量执行，避免重复计算：

```python
executor = StrategyExecutor()

# 策略字典
strategies = {
    "MA_Strategy": MAStrategy(),
    "RSI_Strategy": RSIStrategy()
}

# 方法1：一体式执行（自动计算指标）
all_signals = executor.execute_strategies(strategies, raw_data)

# 方法2：分离式执行（先预计算，再执行）
# Step 1: 批量预计算指标
indicators_dict = executor.batch_calculate_for_strategies(strategies, raw_data)

# Step 2: 批量执行（使用预计算的指标，不重复计算）
all_signals = executor.execute_strategies(
    strategies, 
    raw_data=indicators_dict,    # 传入预计算的指标字典
    calculate_indicators=False  # 不重复计算指标
)
```

**说明**：

- `calculate_indicators=True`（默认）：自动计算指标，每个策略都会调用 `calculator.batch_calculate()`
- `calculate_indicators=False`：从预计算的 `indicators_dict` 读取指标数据，直接执行策略，避免重复计算

### 3. 指标计算流程

```
原始数据 → StrategyManager → StrategyExecutor → IndicatorCalculator
    ↓           ↓                  ↓                  ↓
    ↓     策略管理协调     执行协调统计     指标计算缓存
    ↓           ↓                  ↓                  ↓
交易信号 ← 信号记录事件 ← 策略执行结果 ← 指标计算结果
```

## 📈 重构优势

### 1. 性能优化

- **消除双重缓存**：指标缓存由IndicatorCalculator统一管理
- **批量计算优化**：支持批量计算策略所需指标
- **内存效率**：避免重复存储策略实例和指标数据

### 2. 可维护性提升

- **清晰的职责边界**：每个组件职责单一
- **松耦合设计**：组件间通过接口协作
- **易于测试**：各组件可独立测试

### 3. 可扩展性增强

- **策略类型扩展**：易于添加新的策略类型
- **执行引擎替换**：可替换不同的执行引擎
- **缓存策略定制**：可定制不同的缓存策略

## 🚀 使用示例

### 1. 基础使用

```python
from strategy.strategy_manager import StrategyManager
from strategy.strategy_executor import StrategyExecutor
from strategy.technical_strategy import TechnicalStrategy

# 创建策略管理器
manager = StrategyManager()

# 创建策略
class MyStrategy(TechnicalStrategy):
    def define_rules(self):
        # 定义策略规则
        pass
    
    def generate_signals(self, indicators_data, **kwargs):
        # 生成交易信号
        pass

# 注册策略
strategy = MyStrategy("MyStrategy")
strategy_id = manager.register_strategy(strategy)

# 启动策略
manager.start_strategy(strategy_id)

# 生成信号
signals = manager.generate_signals(strategy_id, raw_data)

# 停止策略
manager.stop_strategy(strategy_id)
```

### 2. 批量执行

```python
# 创建多个策略
strategies = {
    "strategy1": MyStrategy("Strategy1"),
    "strategy2": MyStrategy("Strategy2"),
    "strategy3": MyStrategy("Strategy3")
}

# 批量注册
for strategy_id, strategy in strategies.items():
    manager.register_strategy(strategy)

# 批量启动
manager.start_all_strategies()

# 批量生成信号
for strategy_id in strategies.keys():
    signals = manager.generate_signals(strategy_id, raw_data)
    print(f"{strategy_id}: {len(signals)} signals")
```

## 📖 策略使用方式指南

### 1. 多因子策略 - 单策略使用

**适用场景**：多因子策略内部已经整合了多个因子（PE、ROE、市值等），本身就是一个完整的选股系统。

**使用方式**：直接使用 `StrategyManager` 注册单个策略。

```python
from strategy.strategy_manager import StrategyManager
from strategy.multi_factor.example_strategy import SimpleValueMomentumStrategy

manager = StrategyManager()

# 多因子策略本身包含多个因子，直接使用
strategy = SimpleValueMomentumStrategy(
    name="价值动量策略",
    factor_names=["pe_ratio", "roe", "momentum"],
    top_n=10
)

strategy_id = manager.register_strategy(strategy)
manager.start_strategy(strategy_id)

# 生成信号
signals = manager.generate_signals(strategy_id, stock_data)
```

### 2. 技术指标策略 - 组合使用

**适用场景**：单个技术指标只是单一信号（RSI、MACD、SMA等），需要组合多个策略才能形成完整的交易系统。

**使用方式**：使用 `StrategyManager` + `StrategyPortfolio` 组合模式。

```python
from strategy.strategy_manager import StrategyManager
from strategy.portfolios import BalancedPortfolio

manager = StrategyManager()

# 组合多个技术指标策略
portfolio = BalancedPortfolio()

manager.add_portfolio(portfolio)
```

### 3. 模块化策略组合

系统提供了预定义的策略组合，可以直接使用：

```python
from strategy.portfolios import (
    get_aggressive_growth_portfolio,   # 激进成长组合
    get_conservative_value_portfolio,    # 保守价值组合
    get_balanced_portfolio               # 平衡型组合
)

# 获取预定义组合
portfolio = get_balanced_portfolio()
```

### 4. 自定义策略组合

```python
from strategy.portfolios import BasePortfolio

# 创建自定义组合
my_portfolio = BasePortfolio("MyPortfolio", "我的自定义组合")

# 添加策略
my_portfolio.add_strategy(
    strategy_id="rsi_strategy",
    strategy_type="technical",
    indicators=["rsi"],
    params={"rsi_period": 14, "oversold": 30},
    applicable_stocks=None  # 全局策略
)

my_portfolio.add_strategy(
    strategy_id="macd_strategy",
    strategy_type="technical", 
    indicators=["macd"],
    params={"fast": 12, "slow": 26},
    applicable_stocks=["AAPL", "GOOG"]  # 特定股票
)

# 设置组合参数
my_portfolio.params = {
    "rebalance_frequency": "weekly",
    "stop_loss": 0.05,
    "take_profit": 0.15
}
```

### 5. 设计理念总结

| 策略类型   | 本质               | 使用方式  |
| ------ | ---------------- | ----- |
| 多因子策略  | 因子打分系统（内部已整合多因子） | 单策略使用 |
| 技术指标策略 | 信号触发器（单一指标）      | 组合使用  |

**核心理念**：

- **多因子策略**：因子本身就是"组合"，内部做因子加权
- **技术指标策略**：指标是"原子"的，需要组合才能分散风险
