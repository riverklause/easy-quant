# 条件过滤模块开发指南

## 概述

条件过滤模块（screener）是 Easy-Quant 系统中的股票筛选组件，用于从历史K线数据中快速筛选符合条件的股票。该模块采用并行过滤架构，每个条件独立评估，返回各自的股票列表。

### 核心类

- **FilterCondition**: 过滤条件抽象基类
- **TechnicalCondition**: 技术指标条件基类，继承自 FilterCondition
- **StockScreener**: 股票筛选执行引擎

## 数据格式要求

### 输入格式

```python
stock_data: Dict[str, pd.DataFrame]
```

- **Key**: 股票代码（字符串），如 `"000001"`, `"AAPL"`
- **Value**: pandas DataFrame，K线数据

### DataFrame 要求

- **索引**: 日期时间索引，index.name = `'date'`
- **必需列**: `close`（收盘价）
- **可选列**: `open`, `high`, `low`, `volume`

### 示例

```python
import pandas as pd
import numpy as np

dates = pd.date_range(start='2024-01-01', periods=60)

stock_data = {
    '000001': pd.DataFrame({
        'open': np.random.randn(60) + 10,
        'high': np.random.randn(60) + 11,
        'low': np.random.randn(60) + 9,
        'close': np.random.randn(60) + 10,
        'volume': np.random.randint(1000000, 10000000, 60)
    }, index=dates)
}
stock_data['000001'].index.name = 'date'
```

## 快速开始

```python
from screener import StockScreener, RSIOversold, PriceUp, VolumeSpike

# 准备股票数据
stock_data = {...}

# 创建筛选器
screener = StockScreener()

# 添加条件（每个条件独立并行过滤）
screener.add_condition(PriceUp())
screener.add_condition(RSIOversold())
screener.add_condition(VolumeSpike())

# 执行筛选
results = screener.screen(stock_data)

# 查看结果
for name, stocks in results.items():
    print(f"{name}: {len(stocks)}只")
```

## 条件基类

### FilterCondition

所有条件的抽象基类：

```python
from abc import ABC, abstractmethod
from typing import Any

class FilterCondition(ABC):
    def __init__(self, name: str):
        self.name = name

    @abstractmethod
    def evaluate(self, data: Any) -> bool:
        """评估数据是否符合条件"""
        pass
```

## 自定义条件

可以通过继承 FilterCondition 创建自定义条件：

```python
from screener import FilterCondition

class MyCustomCondition(FilterCondition):
    def __init__(self, param1: int = 10):
        super().__init__(name='MyCustomCondition')
        self.param1 = param1

    def evaluate(self, data) -> bool:
        close = data['close']
        # 自定义筛选逻辑
        return close.iloc[-1] > self.param1
```

## 条件组使用

条件组内的条件为 AND 关系，组内所有条件都满足才算通过：

```python
from screener import StockScreener, PriceUp, RSIOversold, VolumeSpike

screener = StockScreener()

# 添加单个条件
screener.add_condition(PriceUp())

# 添加条件组（组内 AND 关系）
screener.add_condition_group([
    RSIOversold(),
    VolumeSpike()
])

results = screener.screen(stock_data)
# 结果包含: 'PriceUp_1d' 和 'RSI_Oversold+VolumeSpike_1.5x'
```

## 扩展开发

### 开发新条件步骤

1. 在 `screener/conditions/technical/` 目录下创建新文件
2. 继承 `TechnicalCondition` 基类
3. 实现 `_calculate_indicator` 方法计算指标
4. 实现 `evaluate` 方法判断条件
5. 在 `__init__.py` 中导出新条件

### 代码示例

```python
# screener/conditions/technical/new_indicator.py

from screener.filter_condition import TechnicalCondition

class NewIndicatorCondition(TechnicalCondition):
    """新指标条件基类"""
    def __init__(self, name: str, period: int = 14):
        super().__init__(name=name, indicator_name='new_indicator')
        self.period = period

    def _calculate_indicator(self, data):
        """计算指标值"""
        from indicators.technical.xxx import NewIndicator
        indicator = NewIndicator(period=self.period)
        result = indicator.calculate(data)
        if hasattr(result, 'iloc'):
            return result.iloc[-1]
        return result

class NewIndicatorSignal(NewIndicatorCondition):
    """新指标信号"""
    def __init__(self, period: int = 14):
        super().__init__(name='NewIndicator_Signal', period=period)

    def evaluate(self, data):
        value = self._calculate_indicator(data)
        if value is None:
            return False
        return value > 50  # 自定义判断逻辑
```

### 开发规范

1. **指标计算分离**: 将指标计算逻辑放在 `_calculate_indicator` 方法中
2. **空值处理**: 在 `evaluate` 中处理指标计算返回 None 的情况
3. **命名规范**: 条件类名使用描述性命名，如 `RSIOversold`、`MACDGoldenCross`
4. **参数合理**: 提供合理的默认参数，减少使用时的工作量
5. **文档注释**: 为每个条件类添加清晰的文档字符串
